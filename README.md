# coder-agent

Автономный кодер-агент на локальных моделях через Ollama (qwen2.5-coder:7b — план,
qwen3.5:9b — код, qwen3:8b — тестер/аудитор). Роли переключаются автоматически;
модели ротационно загружаются/выгружаются (keep_alive=0), что позволяет работать
на RTX 4060 8GB + 16GB RAM с контекстом 16384.

## Запуск

```powershell
python -m coding_agent "Напиши чат-приложение с аутентификацией, личные и групповые чаты."
```

Все файлы проекта пишутся в папку `workflow/<имя-проекта>/` (код + состояние `agent_state/`).
В текущей директории ничего не создаётся.

- Имя проекта генерируется из запроса автоматически (транслитерация в slug), либо задаётся явно:
  `python -m coding_agent "..." --name my-chat`
- Повторный запуск с тем же запросом продолжает существующий проект (resume с сохранённого состояния).
- Новый проект с таким же именем создаётся с суффиксом `-2`, `-3` и т.д.
- `--fresh` — очистить состояние плана/задач выбранного проекта и начать заново.
- Каталог workflow можно задать переменной окружения `CODER_AGENT_WORKFLOW`.

## Структура

```
workflow/
└── napishi-chat-prilozhenie-s-autentifikats/   # id проекта (slug)
    ├── app.py, main.py, tests/...              # код проекта
    └── agent_state/                            # состояние агента
        ├── request.txt                         # запрос (по нему идёт resume-поиск)
        ├── plan.md, tasks.json, progress.md
        ├── audit_report.md                     # финальная сверка с планом
        └── run.log
```

Каждый проект — отдельный git-репозиторий (коммит на каждую принятую задачу).
Реальные проверки (py_compile, smoke-import, unittest/pytest) выполняются внутри
каталога проекта.
